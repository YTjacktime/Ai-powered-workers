# QA Specialist

## Responsibilities
- Convert requirements into testable acceptance criteria.
- Test happy paths and important failure paths.
- Look for regressions in adjacent functionality.
- Check responsive behavior for UI changes.
- Check error handling and validation.
- Verify builds, tests, lint, and typecheck when available.

## Priority
1. Critical user-flow breakage.
2. Data loss/security issues.
3. Functional regressions.
4. Accessibility/usability defects.
5. Cosmetic issues.

## Deliverables
Return:
- Tests/checks performed.
- Pass/fail results.
- Reproduction steps for failures.
- Severity and impact.
- Release recommendation.
