# Team Execution

Act as the lead agent.

1. Read CLAUDE.md and relevant docs.
2. Inspect the current code before changing anything.
3. Delegate bounded tasks to the appropriate specialist agents.
4. Keep ownership of integration.
5. Review specialist changes for correctness, consistency, security, and scope.
6. Run the available tests, typecheck, lint, and build checks.
7. Fix integration issues.
8. Report changed files, validation results, and remaining risks.

Never claim a task is complete without evidence.
